## 4. RKCIF最小可观测性增量

必须分账：原厂已有IRQ错误计数、procfs、tasklet、watchdog/reset框架；本阶段只
补充缺少的逐stream关联数据。

| 统计 | 候选插点 | 约束 |
|---|---|---|
| FS/FE及最后时间 | `rkcif_irq_pingpong_v1()`状态分类后 | IRQ内只做无阻塞计数和ktime |
| DMA slot/active/no-buffer | `rkcif_update_stream()` Buffer切换处 | 按stream/slot区分 |
| VB2 done/error/sequence | `rkcif_buf_done_prepare()`及tasklet done处 | 同一Buffer只完成一次 |
| IRQ到done延迟 | IRQ快照到VB2 done | 使用原子/最小锁统计min/max/last |
| debugfs快照 | 独立只读文件 | 不在高频路径格式化日志 |
| tracepoint | FS/FE/DMA/VB2/error事件 | 默认关闭，按需启用 |

先输出原始计数和时间戳，不实现自动reset。

## 5. L1 generation-aware timeout

第一版恢复边界：统计 + `vb2_queue_error()` + 用户态关闭/重开，不承诺Host无感重启。

设计规则：

1. 每次STREAMON递增 `stream_generation`；
2. delayed work保存创建时generation；
3. 每次成功VB2 done更新heartbeat；
4. work只在streaming且generation匹配时判断超时；
5. 超时调用`vb2_queue_error()`并保存快照；
6. STREAMOFF/close/remove/suspend必须`cancel_delayed_work_sync()`；
7. 不由旧work处理新会话，不在第一版跨Sensor/CSI/ISP自动重启。
