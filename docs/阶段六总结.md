## 3. 故障发现和修复价值

长稳不是只证明“能跑”：它连续发现并关闭了两个真实缺口。

1. 热验收工具原单次上限10000，不能覆盖57600对；扩展上限后保持采集逻辑不变。
2. MLX参考API定义的`0x7FFF` frame data error此前被第一次即升级为永久queue
   error。修正为丢弃Subpage、重新配对、记录invalid；连续超过8次才fatal，
   I2C/control/ready timeout仍立即传播。

最终2小时中真实出现2个坏Subpage但流未中断，证明该策略不是只通过人工构造。
