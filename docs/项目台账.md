## 1. 台账用途和维护规则

本文件记录项目从环境建立到最终验收的连续工作主线，供日常回顾和新对话交接使用。
阶段设计、硬件证据、测试日志和技术结论仍写入对应专项报告，本台账只保留摘要和入口。

- 所有时间使用 `Asia/Shanghai`（UTC+08:00）。有原始日志时记录精确时间；只有报告日期时明确标注“具体时刻未单独记录”。
- `已验证` 必须有真实构建日志或板端日志；只有源码、编译和静态检查时不得写成真机通过。
- 每完成一项工作就在第 3 节追加记录，并同步第 2 节当前交接状态和第 4 节下一步。
- 厂商已有能力与个人新增实现分开记账；原厂 IMX415、Media Graph、RKCIF/RKISP 能力不计作个人新增成果。
- 阶段一只有在真机稳定读取参考签名并保存日志后，才创建 `阶段一总结.md` 并把状态改为通过。

## 4. 下一步和后续里程碑

1. `P1.1` 收尾：功能门禁已通过；补录连接器照片、完整串口启动输出及必要的电源/MCLK/GPIO 波形，不阻塞 P1.2 代码开发。
2. `P1.2 / 部署门禁`：已完成；后续真机日志必须记录 U-Boot 下载的新 DTB 大小和 Linux 运行时节点，防止误用旧载荷。
3. `P1.2`：阶段二目标路径已通过；补充的寄存器 readback、物理波形和原厂 A/B 作为后续审计材料，不阻塞进入阶段三。
4. `P1.3`：已完成；独立 Sensor-RKCIF-RKISP graph、正式 RAW/NV12、300/3000 帧、Controls 动态效果及正常停流回收通过。ISP IQ/标准色卡画质作为后续专项，不冒充当前结论。
5. `P1.4`：板端功能门禁已通过；当前无测量仪器，电压和400 kHz波形不纳入本阶段；BAA/BAB/FOV型号在项目二标定前确认。
6. `P1.5`：built-in自动probe、NVMEM和200对/10周期正式验收通过，阶段已关闭。
7. `P1.6`：双路基线、逐stream统计/trace、L1 EIO、100次启停、2小时长稳和结束后重开全部通过，阶段已关闭。
8. `P1.7`：外置LED GPIO/PWM和完整可靠性矩阵；LED硬件未具备时不阻塞项目二。
9. 项目一核心相机BSP V1已通过，项目二可进入双路时间匹配、温度算法、区域映射、RGA/RKNN、DMA-BUF流水线和MPP/RTSP；补光状态机等待P1.7外部硬件。
