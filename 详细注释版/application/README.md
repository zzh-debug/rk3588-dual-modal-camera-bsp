# 项目一应用层代码占位

当前阶段没有项目一应用层采集程序。阶段一只包含：

- 内核外置最小 I2C 驱动；
- 实验 DTS/DTB；
- 板端 shell 验收脚本。

`modprobe` 和验证脚本不是 V4L2 应用层采集程序。等进入以下阶段后，再把对应
应用源码的详细注释镜像加入本目录：

1. 独立 IMX415 RAW/V4L2 抓帧工具；
2. MLX90640 V4L2 Meta/VB2 ABI 验证工具；
3. 双路 timestamp 配对和可靠性测试工具；
4. 用户态关闭、重开和错误恢复工具。

没有实际代码前不创建伪实现，也不把 SDK 厂商示例复制后称为项目应用。
